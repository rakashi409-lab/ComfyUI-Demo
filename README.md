# ComfyUI 演示程序

一个单文件的 ComfyUI 界面模拟程序，用于工作流搭建演示。无需安装任何软件或模型。

## 在线演示

直接访问：[https://dafar.github.io/ComfyUI-Demo/ComfyUI.html](https://dafar.github.io/ComfyUI-Demo/ComfyUI.html)

## 使用方法

双击 `ComfyUI.html`，用浏览器（推荐 Chrome / Edge）打开即可。

## 基本操作

| 操作 | 说明 |
|---|---|
| 双击 / 右键空白画布 | 弹出节点搜索，添加节点 |
| 左键拖空白处 | 平移画布 |
| 鼠标中键拖动 | 任意位置平移画布（包括节点上） |
| 滚轮 | 缩放画布 |
| 拖动节点标题栏 | 移动节点 |
| 拖动节点右下角三角 | 调整节点大小 |
| 从输出端口拖线到输入端口 | 连接节点（颜色类型匹配才能连） |
| 从已连接的输入端口拖动 | 断开并接管该连线 |
| Delete | 删除选中节点 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做 |
